# Weather App

## Демонстрация работы

В приложении есть возможности выбора города по кнопке и поиска городов
При выборе города показываются случайные данные погоды, которые генерируются с помощью Math.random

2.  Выбор города по кнопке<br>
    Осуществляется после нажатия на кнопку города
    ![Img 2](./src/assets/images/2.png)
3.  Поиск города<br> 
    Осуществляется после ввода значения в поле поиска и нажатия на кнопку "поиск"
